gptokeyb
========

This package does not contain gptokeyb. The launch script starts the copy that the user's PortMaster
installation provides ($GPTOKEYB, in the PortMaster control folder), without a mapping file, and only
so that its Select+Start hotkey can close the game. gptokeyb is part of PortMaster:
https://portmaster.games/gptokeyb-documentation.html . Its licence is determined by the PortMaster
project (the documentation page does not state one); it is not bundled here, so nothing needs to be
redistributed from this package.
