# N8: Airways in flight plans

Phase 3 · Effort: high · Depends: none · Branch: `wp/N8-airways`

## Why

Airway data is already in the nav pack (`airways.csv`, `NavDb::airway()`), but plans ignore it:
- Import reads the `via` field and drops it (`src/nav/README_FMS.md` line 73), and export writes
  `DRCT` for every leg.
- A file that names an airway but skips its intermediate fixes is flown direct.
- The in-game quick plan offers only "direct" or "navaids along the great circle", not airways.

## Read

- `docs/NAVIGATION.md` §2 to §2.2 (`grep -n '^### 2' docs/NAVIGATION.md`)
- `src/nav/README_FMS.md` lines 25–80
- `src/nav/FlightPlan.h` (whole file), `src/nav/Fms.h`
- `src/nav/NavDb.h` lines 30–75 (`AirwayPoint`, `airway()`)
- The quick-plan builder: `grep -n -i 'quick\|great circle\|navaids along' src/nav/*.h src/ui/PlanScreens.cpp`
- `docs/DATA.md` §5.7 (`airways.csv`)

## Owns

`src/nav/Fms*`, `src/nav/FlightPlan*`, `src/nav/README_FMS.md`, `tests/nav/`, NAVIGATION §2.

**Also touches:** `src/ui/PlanScreens.cpp` (a VIA AIRWAYS quick-plan choice), `src/ui/MapPage.cpp`
(the airway name on a leg label), only as small additive edits.

## Do

1. Keep `via` on each leg (an additive field on the plan leg, empty means direct) and write it back
   on export.
2. Import: when a leg's `via` names an airway and both its fixes are on that airway, insert the
   airway fixes in between that the file left out, in order. Unknown airway or fix: keep the leg
   direct and add a warning to the build result.
3. Quick plan "VIA AIRWAYS": from the departure, go to the nearest airway fix within 30 NM. Find
   the shortest route on the airway graph (Dijkstra by distance, legs whose MEA is above the
   cruise altitude excluded) to the airway fix nearest the destination, then go direct.
   Fall back to the existing quick plan when there is no route.
4. Map page and mini nav show the airway name on its legs.
