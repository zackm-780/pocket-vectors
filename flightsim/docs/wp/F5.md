# F5: Stall warning by flap setting

Phase 2 · Effort: medium · Depends: none · Branch: `wp/F5-stall-warn-flaps`

## Why

Each profile has one `stall_warn_alpha_deg`, but the airliners' stall angle of attack falls with
flap. The 737 profile measures 14.6° clean, 14.3° at flaps 5, 12.9° at flaps 15, 11.8° at flaps
30 and 11.2° at flaps 40, against one 10.5° warning. The 747 goes from 18.1° clean to 9.2° at
full flap. One threshold either warns late with flaps or nags when clean. This is an open F2
follow-up in WORK_PACKAGES.

- `src/core/AircraftProfile.h` (find `stallWarnAlphaDeg` and the flap-detent fields)
- `src/sim/ProfileLoader.cpp` around line 84 (`stall_warn_alpha_deg`)
- The two uses: `src/sim/FlightModel.cpp` around line 681, `src/hud/HudLogic.cpp` around line 560

  `B747.ini` (lines 1–60)
- `tests/fleet/README.md` (how stall speeds and angles are measured)

## Owns

**Also touches (additive):** `core/AircraftProfile.h` (a new
`std::vector<float> stallWarnAlphaByFlapDeg`, empty by default), `FlightModel.cpp` and
`HudLogic.cpp` (one shared helper that returns the threshold for the current flap position).

## Do

1. New key `stall_warn_alpha_by_flap_deg = a0, a1, …`, one value per flap detent in the profile's
   order. Interpolate by the current flap position. When the key is absent, keep the single value.
2. Values: the measured stall angle at each detent minus the margin the fleet README uses for
   the single value today. Do the 737, B747, A320, MD11 and 787-8 where the profile comments carry
   measurements. Measure the missing detents with the fleet test harness.
3. Use one helper in both places, so the HUD and the flight model always agree.
