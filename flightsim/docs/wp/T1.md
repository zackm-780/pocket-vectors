# T1: Device session 1, confirm the post-1.0 build

Phase 1 · Who: the owner on the RG40XXH, then a builder writes it up (effort medium) · Depends: none

## Why

Five changes landed after the v1.0.0 tag (pull requests #5–#9: button labels, Help, release
tooling, mini nav, world overlays). All of them say "needs device test", and the frame rate has
never been measured on the handheld. This session tests the v1.1.0 release.

## Get the build onto the card

1. Download `pocket-vectors-v1.1.0-game.zip` from the
   [v1.1.0 release](https://github.com/zackm-780/pocket-vectors/releases/tag/v1.1.0).
2. Unzip it into `Roms/PORTS` over the 1.0 install by **merging** folders. In the macOS Finder,
   "Replace" on `flightsim/` deletes `data/`. Alternatively run
   `flightsim/tools/sdcard/make_sdcard_zip.py` with the game zip and the 1.0 data zip.
3. If you created `flightsim/conf/controls.ini` for the 1.0 A/B workaround, delete it. Otherwise
   you are testing your override, not the new defaults.
4. Help → About should say `VERSION 1.1.0`. The probe is not in the release zip; for the optional
   probe run, use the `flightsim-sdcard-PORTS` artifact of the newest green **device** run.

## Checklist (tick and note what you see)

**Buttons, base layer**
- [ ] A = gear, B = brakes, X = speedbrake, Y = HUD declutter (X/Y were never confirmed)
- [ ] Select opens the map; the Menu key also opens it; Select+Start quits
- [ ] R3 click does nothing; L3 cycles the overlays (message `OVERLAYS …`)
- [ ] Optional: run the probe and press each face button as soon as its prompt appears

**Frame rate** (Settings → SHOW FPS → ON; fly each case for 60 s)
- [ ] KPDX runway start (the Portland view is 46k triangles, over the 40k budget)
- [ ] Cruise start on the KPDX-KOTH plan
- [ ] KOTH final, 6 NM
- [ ] Night final at KPDX
- [ ] KPDX runway again with OVERLAYS = ALL and MINI NAV = ON
- [ ] Note the lowest number you see in each case

**New features**
- [ ] Overlays: L3 steps OFF, ROUTE, ROUTE+PATH, AIRPORTS, ALL; each is readable on the KPDX
      approach and at cruise
- [ ] Toggle an overlay, quit with Select+Start, relaunch: the setting is kept
- [ ] Mini nav (pause → MINI NAV): readable on a straight leg, in a turn and on the approach;
      hidden in HUD MIN (Y) and on the map page
- [ ] Help: every page readable at 640×480; the button test names the last press; Swap A/B
      rewrites `conf/controls.ini` and keeps its other lines; About shows the attribution
- [ ] The pause menu (now 10 rows) fits and reads

**While you are there**
- [ ] Menu → flying time with a stopwatch (budget 15 s)
- [ ] Audio crackle or dropouts
- [ ] Night city lights (speckle size, shimmer) and low-visibility fog
