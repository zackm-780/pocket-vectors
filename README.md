# retro-games

Games for the Anbernic RG40XXH handheld (stock OS, delivered as PortMaster ports).

| Project | Status | What it is |
|---|---|---|
| [`flightsim/`](flightsim/README.md) | Playable on the RG40XXH (first device flights October 2026) | First-person flight sim with HUD, real terrain, real airports, flight plans and instrument approaches. Uses the JSBSim flight model. Handheld install: [`flightsim/INSTALL.md`](flightsim/INSTALL.md). |

Contributors and agents: start with [`CLAUDE.md`](CLAUDE.md).

## Contributing

Contributions are welcome. Fork the repository, make your change on a branch, and open a pull
request. Read [`CLAUDE.md`](CLAUDE.md) and
[`flightsim/docs/CONVENTIONS.md`](flightsim/docs/CONVENTIONS.md) first; open work is listed in
[`flightsim/docs/WORK_PACKAGES.md`](flightsim/docs/WORK_PACKAGES.md).
